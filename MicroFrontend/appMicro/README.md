## Installation
This project was generated  with [Ionic CLI](https://ionicframework/com) version 6.20.1.

* `git clone git@github.com:adldigitallabs/bavv-mb-frontend-app-mf.git` this repository
* change into the new directory `cd bavv-mb-frontend-app-mf` and
* run `npm run android:stg` to generate apk or `npm run ios:stg` to generate ipa file.
