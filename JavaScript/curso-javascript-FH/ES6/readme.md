# INCLUSIONES EN ES6

ES6 agrego nuevos tipos de variables que se pueden incluir en los arreglos. Estos son:

- **let**: Una variable que solo existe dentro del bloque de código en el que se declaró.
- **const**: Una variable que no puede ser reasignada después de ser declarada.

ES6 agrego nuevos segmentos de caracteres como por ejemplo: StartsWith, endsWith, includes, repeat, etc.



ES6 agrego algunos nuevos tipos de datos que se pueden incluir en los arreglos. Estos son:

- **Symbol**: Un tipo de dato único que se puede usar como identificador de propiedades de objetos.
- **Object**: Un tipo de dato que se puede usar para representar un objeto en JavaScript.
